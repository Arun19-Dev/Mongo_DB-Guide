MongoDB Commands

Learn commands one by one.

1. Create / Switch Database

Select a database. If it doesn't exist, MongoDB will create it when you store data. 

use collegeDB

2. Show Current Database

Shows which database you are currently using. 

db

3. Show Databases

Displays databases that contain data. 

show dbs

4. Create Collection

Creates a collection called students. 

db.createCollection("students")

5. Insert One Document

Adds one student document. 

db.students.insertOne({
    name: "Arun",
    age: 22,
    course: "MERN"
})

6. Insert Multiple Documents

Adds multiple students at once. 

db.students.insertMany([
    {
        name: "Arun",
        age: 22
    },
    {
        name: "Rahul",
        age: 21
    }
])

7. Find All Documents

Gets every student. 

db.students.find()

8. Find One Document

Finds the first matching document. 

db.students.findOne({
    name: "Arun"
})

9. Update Document

Changes an existing field. 

db.students.updateOne(
    { name: "Arun" },
    {
        $set: {
            age: 23
        }
    }
)

10. Delete Document

Deletes one matching document. 

db.students.deleteOne({
    name: "Arun"
})

11. Find Using Condition

Find students whose age is greater than 20. 

db.students.find({
    age: {
        $gt: 20
    }
})

12. Delete Many

Deletes multiple matching documents. 

db.students.deleteMany({
    course: "Java"
})
